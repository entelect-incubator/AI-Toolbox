## Key SDD Concepts

- Spec-first: write a well-thought-out spec first, then use it in AI-assisted development.
- Spec-anchored: keep the spec after task completion for evolution and maintenance.
- Spec-as-source: make the spec the long-term source file; prefer editing spec over direct code edits where feasible.
