# Specs Layer

This folder is the primary input for AI-assisted generation.

Structure:
- system: system-level capabilities and boundaries
- features: feature specs used for module generation
- api: API-level contracts and examples
- data: data contracts and schema notes
- templates: reusable spec templates

Rules:
- Do not generate production code without a feature spec.
- Keep specs deterministic and measurable.
- Update specs first when requirements change.
