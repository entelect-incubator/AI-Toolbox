# Quality Scorecard And Cadence

Use this monthly to measure whether AI-assisted delivery is improving outcomes.

## Cadence

- Weekly: review open high-priority quality and security risks
- Monthly: scorecard review with BA, Dev, QA leads
- Quarterly: tooling and workflow adjustments

## KPI Set

- PR cycle time
- Defect escape rate
- Reopen rate after fixes
- Security issue closure time
- Test coverage on changed lines
- Percentage of PRs with full acceptance-criteria mapping

## Practical Examples

Example: defect escape trend
- Baseline: 8 escaped defects/month
- Current: 3 escaped defects/month
- Action: keep current test gate and improve boundary-path tests

Example: PR cycle time regression
- Baseline: 2.1 days
- Current: 3.4 days
- Action: reduce review noise and tighten prompt scope for smaller changes
