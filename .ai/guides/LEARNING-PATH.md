# Learning Path: Add AI Properly

Use this path if you are learning and want a clear order.

## 30-Minute Fast Start

1. Read `.ai/guides/START-HERE.md`
2. Run `.ai/guides/TEAM-KICKOFF-CHECKLIST.md`
3. Read `.ai/guides/AI-INSTRUCTIONS.md`
4. Read `.ai/guides/AI-WORKFLOWS.md`
5. Open your role playbook in `.ai/roles`

Outcome:
- You know where to start, what quality means, and how BA/Dev/QA collaborate.

## 90-Minute Practitioner Path

1. Complete Fast Start
2. Read `.ai/guides/PROMPTING-FOR-ENGINEERS.md`
3. Read `.ai/guides/QUALITY-AUDIT.md`
4. Read `.ai/guides/SCAFFOLD-AND-ACCELERATE.md`
5. Review `.ai/references/sdd-references.md`

Outcome:
- You can run a spec-driven workflow with clear validation and audit gates.

## UI/Product Track (Optional)

1. Read `.ai/guides/DESIGN-MD-GUIDE.md`
2. Copy `.ai/specs/templates/DESIGN.md` into your project root as `DESIGN.md`
3. Apply the same design rules across generated UI work

Outcome:
- AI-generated UI is consistent and reviewable.

## Practical Examples

Example: BA learning sprint
- Day 1: complete Start Here and draft one feature spec.
- Day 2: refine acceptance criteria with QA input.
- Day 3: handoff spec package to Dev.

Example: Dev learning sprint
- Day 1: run one prompt from Prompting For Engineers.
- Day 2: implement one thin vertical slice.
- Day 3: run audit and security check before PR.
